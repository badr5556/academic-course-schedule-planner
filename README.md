# Academic Course & Schedule Planner

## 📌 Project Overview
The **Academic Course & Schedule Planner** is a centralized web-based application designed to streamline semester planning, course registration, and academic advising for university students, faculty advisors, and system administrators.

## 🛠️ System Architecture & Tech Stack
* **Architecture:** Model-View-Controller (MVC) Design Pattern.
* **Backend Framework:** Python (Flask) / C# (.NET Core).
* **Database:** Relational Database Management System (PostgreSQL / SQLite).
